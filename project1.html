Redesigning the Dwarf Fortress Website

UX/UI redesign for the Dwarf Fortress Website

Context & Problem

I chose this website because it's a little hard to tell what links I should be clicking, where I should go to download the game, and overall it's a lot of information to process at once.

Efficiency

All the information on where you want to go is easily accessible on the navigation menu at the top.

There are multiple download buttons, making it easier for users to navigate.

👥
Audience & Research

The primary audience includes health-conscious individuals aged 25-45 who want to track various health metrics but aren't necessarily tech-savvy.

I conducted user interviews with 8 current and 5 former users to understand pain points and expectations. Key findings included:

  • Data visualization was confusing and required too many taps
  • Important features were buried in complex navigation
  • Users wanted more personalized insights based on their data

✏️
Design Iterations

I explored multiple design directions, focusing on simplifying the interface while making data more accessible and actionable.

Iteration 1: Dashboard Redesign

The first iteration focused on reorganizing the dashboard to highlight key metrics and recent activities.

User feedback: Better than original but still too cluttered. Users wanted more visual representation of data.

Iteration 2: Visual Data Approach

The second iteration emphasized visual data representation with customizable widgets and a simplified navigation system.

User feedback: Much improved visual clarity, but some users found the customization options overwhelming.

Iteration 3: Final Design

The final design balanced visual data representation with intuitive navigation and progressive disclosure of advanced features.

Key improvements:

  • Simplified navigation with a tab bar for primary functions
  • Data visualization with clear trends and actionable insights
  • Personalized recommendations based on user data
  • Progressive disclosure of advanced features

🎮
Conclusion & Learnings

The redesigned app was tested with 12 users, showing a 40% improvement in task completion rates and significantly higher satisfaction scores.

Key learnings:

  • Visual data representation is crucial for health tracking apps
  • Progressive disclosure helps balance simplicity with feature richness
  • Personalized insights create more engagement than raw data
  • Consistent feedback loops with users throughout the design process leads to better outcomes

This project reinforced the importance of user-centered design and iterative testing in creating effective digital health tools.
